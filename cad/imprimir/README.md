# Piezas para imprimir

STL o 3MF **finales** de cada pieza impresa. Todavía vacío.

- Un archivo por pieza, con el código del CAD: `CB-210_Torre_Cintura_parte1.stl`.
- Exportar desde `cad/solidworks/` (o `cad/herramienta/`) recién cuando la pieza esté aprobada.
- Material: PETG, ≥ 4 perímetros. Impresora: Ender 3 V2 (220 × 220 × 250 mm).
- Lista de piezas y cantidades: [bom/BOM.md](../../bom/BOM.md#piezas-impresas).
